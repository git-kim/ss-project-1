# 2017~2025년 소방서 6개소 공공데이터로 바라본, 평균 기온과 소방 응급 환자 발생의 연관성

> **기온이 높아질수록 구급 수요가 증가하는가? 특히 고령층에서 더 크게 나타나는가?**

2017~2025년 소방청 구급 데이터와 기상청 시간별 기상 데이터를 결합하여, **기온과 구급 출동·이송의 관계를 분석**한 프로젝트입니다.

## 🎯 핵심 결과

* **30℃ 이상에서 구급 수요가 뚜렷하게 증가**
* 특히 **80세 이상**에서 증가 폭이 큰 편
  * 10~15℃ 대비 30℃ 이상: **출동 +56%, 이송 +77%**
* 하루 중 구급 수요는 **오전 9시 최대, 새벽 4~5시 최소**
* **25℃를 넘으면 오전부터 밤까지 전반적으로 증가**
* 연도별 구급 수요 변화는 기온만으로 설명되지 않아 **연도 효과를 함께 통제**
* 관측 데이터의 과대 산포를 확인하여 **포아송 회귀 대신 음이항 회귀**를 적용

> 결론: **고온 환경, 특히 30℃ 이상에서 고령층의 구급 수요가 더 크게 증가하는 패턴이 확인되었습니다.**
> 단, 분석 대상은 6개 소방서이므로 전국 단위로 일반화할 수 없습니다.

## 📊 사용 데이터

**소방청**

* 구급활동정보
* 구급환자이송정보
* 2017. 1. ~ 2025. 12.

**기상청**

* 시간별 기온·습도·풍속
* 2017. 1. ~ 2025. 12.

분석 대상은 서울·대구·부산·원주의 **6개 소방서**이며, 최종 분석 단위는 **소방서·연월·시간대**입니다.

> 원천(raw) 데이터는 저장소에 포함하지 않았습니다. 대신 데이터 수집 코드, 가공 코드, `data/processed/base_table.csv`, 분석 결과물을 제공합니다.

## 🔄 데이터 엔지니어링

```text
소방청 API ─┐
            ├─ 전처리/표준화 ─┐
기상청 데이터 ─┘              │
                              ▼
                '지역, 연월, 시간대' Join
                              │
                              ▼
                  data/processed/base_table.csv
                              │
                              ▼
                         EDA / 통계분석
                              │
                              ▼
                        outputs/main
```

데이터 품질을 확인한 뒤 연령값 표준화, 결측 처리, 지역·시간 단위 집계, `many_to_one` Join 검증을 수행했습니다. 분석과 입출력 기능도 모듈화하여 재실행할 수 있도록 구성했습니다.

## 📈 주요 분석

* 기온 구간별 출동·이송 변화
* 시간대·기온별 구급 수요
* 연령대별 기온 반응
* 연도·월별 추세
* **B-spline 기반 비선형 회귀**
* **Negative Binomial Regression**
* 소방서별 **IRR (Incidence Rate Ratio)** 비교

포아송 회귀의 과대산포를 검증한 후 음이항 회귀로 변경했으며, 소방서별 기온 반응 차이를 고려했습니다.
